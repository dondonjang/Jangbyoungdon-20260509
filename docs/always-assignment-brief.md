# 과제 1. 고객 문제 실험 설계 및 MVP 구체화

## 1. 어떤 상품 카테고리에서 경험하는 문제인지

**반복 구매 생필품(향후 식료품등)**

예: 물티슈, 세제, 화장지, 샴푸, 바디워시, 생수, 우유, 계란, 아이 간식, 냉동식품, 다이어트/건강식품, 반려동물 용품 등

## 2. 어떠한 문제인지

한국의 35-50세 여성 소비자는 가정 내 반복 구매 품목을 관리하는 경우가 많다. 
이때 가장 큰 불편은 "이미 사는 상품인데도 매번 다시 탐색해야 한다"는 점이다.

반복 구매 상품은 완전히 새로운 탐색이 아니다. 사용자는 이미 선호 브랜드, 가족의 취향, 가격 민감도, 배송 선호, 대체 가능 범위를 어느 정도 알고 있다. 그런데 실제 구매 순간에는 다음 판단을 매번 다시 해야 한다.

- 지난번에 샀던 동일 상품이 지금도 최저가인지 확인해야 한다.
- 같은 상품처럼 보이지만 용량, 개수, 리뉴얼 버전, 판매처 구성이 달라 단순 가격 비교가 어렵다.
- 쿠폰, 배송비, 묶음 구성, 정기 할인, 카드 할인 때문에 실제 체감 가격이 달라진다.
- 품절되었거나 가격이 올랐을 때 어떤 대체 상품이 괜찮은지 다시 검색해야 한다.
- 가족이 쓰는 상품은 실패 비용이 커서 무작정 저렴한 상품으로 바꾸기 어렵다.

즉, 문제의 본질은 "상품 탐색" 자체보다 **반복 구매 상품의 재구매 의사결정 비용**이다.

## 3. 강한 페인포인트를 느끼는 고객 페르소나

### Persona

**40대 초반, 초등학생 자녀가 있는 맞벌이 여성**

- 가정 내 생필품/식료품 구매를 주로 담당한다.
- 쿠팡, 마켓컬리, 네이버쇼핑, 이마트몰, 올웨이즈 등을 함께 사용한다.
- 평일에는 시간이 부족하고, 장보기는 주로 출퇴근길이나 밤 시간에 모바일로 처리한다.
- 가족이 반복적으로 쓰는 브랜드와 상품이 있다.
- 가격은 중요하지만, 실패 확률이 높은 대체 상품에는 보수적이다.

### 왜 강한 페인포인트를 느끼는가

첫째, 구매 빈도가 높다. 생필품/식료품은 한 번의 고관여 구매가 아니라 매주 또는 매월 반복된다. 작은 불편도 누적되면 큰 시간 비용이 된다.

둘째, 비교 기준이 복잡하다. 단순 최저가가 아니라 용량, 개수, 배송비, 쿠폰, 판매처 신뢰도, 가족 선호까지 함께 판단해야 한다.

셋째, 실패 비용이 있다. 아이가 먹는 간식, 가족이 쓰는 세제/샴푸, 피부에 닿는 제품은 잘못 바꾸면 반품이나 재구매로 이어진다.

넷째, 책임이 한 사람에게 몰린다. 가정 내 반복 구매 담당자는 가족의 재고, 취향, 예산을 함께 관리해야 하므로 구매 결정 피로가 크다.

## 4. 해당 문제를 어떻게 제품적으로 해결할 수 있는지

### Product Concept

**AI 장바구니 비서**

사용자가 자주 사는 상품 링크 또는 상품명을 입력하면, AI Agent가 해당 상품을 기억하고 이후 재구매 시점에 동일 상품 최저가, 구매 가능한 판매처, 유사 대체 상품을 비교해주는 서비스다.

핵심은 사용자가 매번 검색 조건을 다시 만들지 않게 하는 것이다. AI Agent는 사용자의 반복 구매 맥락을 저장하고, "이 상품을 다시 살 때 지금 가장 합리적인 선택이 무엇인지"를 대신 정리한다.

### MVP 정의

MVP는 모든 쇼핑 문제를 해결하지 않는다. 가장 반복적이고 검증 가능한 흐름 하나에 집중한다.

**MVP 핵심 플로우**

1. 사용자가 채팅창에 상품 상세 페이지 링크를 입력한다.
2. AI Agent가 상품명, 브랜드, 용량, 핵심 속성, 동일 상품 검색 키워드, 유사 상품 검색 키워드를 추출한다.
3. 상품을 `자주 사는 상품`에 저장한다.
4. 저장된 상품 화면에서 동일 상품 가격 비교 후보를 보여준다.
5. 가격이 높거나 품절에 가까운 경우를 대비해 유사 추천 상품 후보를 함께 보여준다.
6. 사용자는 최저가 또는 대체 상품 구매 링크로 이동한다.

**MVP 범위**

| 구분 | MVP 포함 |
| --- | --- |
| 입력 | 상품 상세 링크 입력 |
| 저장 | 자주 사는 상품 목록 |
| 분석 | AI 기반 상품명 정제, 속성 추출, 검색 키워드 생성 |
| 비교 | 동일 상품 후보 가격 비교 |
| 추천 | 유사 대체 상품 후보 노출 |
| UX | 채팅형 입력, 저장 상품 탭, 구매 링크 이동 |

**MVP에서 제외**

| 제외 항목 | 이유 |
| --- | --- |
| 모든 커머스 동시 지원 | 초기 검증 범위가 과도해짐 |
| 자동 결제/주문 | 정책/신뢰/책임 범위가 큼 |
| 완전한 개인화 추천 | 반복 구매 저장 데이터가 먼저 필요함 |
| 계정 기반 가족 공유 | 핵심 가치 검증 이후 확장 가능 |
| 실시간 최저가 보장 | MVP에서는 후보 비교와 의사결정 보조가 우선 |

## 5. 실험 설계

### 핵심 가설

35-50세 여성 소비자는 반복 구매 생필품을 다시 살 때, 상품을 새로 검색하는 것보다 "내가 자주 사는 상품 기준으로 동일 상품/대체 상품을 정리해주는 AI Agent"에 더 높은 편의와 신뢰를 느낀다.

### 실험 질문

- 사용자는 자주 사는 상품을 직접 저장할 의향이 있는가?
- 저장 이후 다시 구매할 때 가격 비교/대체 상품 추천을 실제로 클릭하는가?
- AI가 제안한 동일 상품/유사 상품 구분을 신뢰하는가?
- 단순 최저가보다 "내가 원래 사던 상품 기준 추천"이 더 유용하게 느껴지는가?

### MVP 실험 방식

| 단계 | 실험 | 확인할 것 |
| --- | --- | --- |
| 1 | 35-50세 여성 10-20명에게 최근 반복 구매 상품 3개를 입력하게 한다 | 저장할 만큼 반복 구매 문제가 실제로 있는지 |
| 2 | 상품 링크 입력 후 동일 상품/유사 상품 후보를 보여준다 | 추천 결과를 이해하고 신뢰하는지 |
| 3 | 최저가/대체 상품 CTA를 제공한다 | 실제 구매 의도 클릭이 발생하는지 |
| 4 | 사용 후 인터뷰를 진행한다 | 어떤 기준이 부족했는지, 어떤 상황에서 다시 쓸지 |

### Success Metrics

| 지표 | 의미 |
| --- | --- |
| 상품 저장 완료율 | 입력 흐름이 충분히 쉬운지 |
| 저장 상품당 비교 후보 조회율 | 저장 이후 가치가 있는지 |
| 구매 링크 클릭률 | 추천/비교가 행동으로 이어지는지 |
| 유사 추천 클릭률 | 대체 상품 추천이 실제 문제를 푸는지 |
| 재방문/재조회율 | 반복 구매 서비스로 작동하는지 |
| 정성 만족도 | "다음 장보기 때 다시 쓰겠다"는 반응이 있는지 |

### MVP 성공 기준

- 테스트 사용자의 60% 이상이 반복 구매 상품을 2개 이상 저장한다.
- 저장 상품을 본 사용자 중 40% 이상이 가격 비교 또는 추천 상품 CTA를 클릭한다.
- 인터뷰에서 "다음에 다시 살 때 유용할 것 같다"는 응답이 과반 이상 나온다.
- 부정 피드백의 핵심이 "문제 자체가 불필요하다"가 아니라 "지원 커머스/추천 품질/가격 정확도를 더 개선해달라"에 가깝다.

## 6. 왜 AI Agent가 적합한가

이 문제는 단순 검색 UI보다 AI Agent가 적합하다.

- 상품명, 용량, 구성, 브랜드, 리뉴얼 표현이 쇼핑몰마다 달라 정규화가 필요하다.
- 동일 상품과 유사 상품의 경계는 단순 키워드 매칭만으로는 부족하다.
- 사용자의 반복 구매 맥락을 기억하고 다음 구매 때 이어서 도와주는 형태가 자연스럽다.
- 사용자는 "검색 조건을 직접 조합"하고 싶은 것이 아니라 "내가 원래 사던 것 기준으로 지금 뭘 사면 되는지"를 알고 싶다.

## 7. 제출용 한 문장 요약

한국의 35-50세 여성 소비자는 생필품/식료품을 반복 구매할 때 동일 상품 가격 비교와 실패 없는 대체 상품 탐색에 지속적인 피로를 느낀다. AI 장바구니 비서는 사용자가 자주 사는 상품을 저장하면, AI가 상품을 구조화하고 동일 상품/유사 상품 후보를 정리해 매번 반복되는 재구매 의사결정 비용을 줄이는 MVP다.
